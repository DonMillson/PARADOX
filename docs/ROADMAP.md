# PARADOX Roadmap

## Target
- 30–50 original roles
- 15 Impostor / 15 Crewmate / 10 Neutral initially
- Paradox Meter and global Paradox Events
- English + Polish localization
- custom map: Paradox Station
- host configuration
- PC first, Android adapter after the shared core is stable
- multiplayer synchronization and mod-version handshake

## Delivery order
1. Reliable build pipeline
2. Among Us/BepInEx/Reactor bootstrap
3. Version handshake and multiplayer protocol
4. Localization (EN/PL)
5. Paradox Meter
6. First playable role pack: Doppelganger, Parasite, Anomaly, Observer, Witness
7. Host role settings
8. Remaining roles in small packs
9. Paradox Station
10. Android adapter
11. Balance, QA and releases

## Rule
New gameplay systems are added in small testable stages. A role must not require editing every other role.
